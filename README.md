# GTW_DASHBOARD 🚀

A web-based **Calibration Management System Dashboard** designed to track, manage, and analyze equipment calibration schedules, history, and compliance metrics in real-time.

## 💻 Tech Stack & Built With
* **Framework:** ASP.NET Web Forms
* **Languages:** C#, HTML5, CSS3, JavaScript
* **Styling Assets:** FontAwesome Icons, Custom Vector Components

## 📂 Project Structure Overview
* `/AdminPage` — Administrative control consoles and user management setups.
* `/DueReports` — Compliance tracking modules and upcoming calibration schedules.
* `/bin` — Compiled application logic binaries and system dependencies.
* `/css` & `/js` — Core visual layouts, responsiveness elements, and interface scripting.
* `/vendor` — Third-party UI dependencies and rendering frameworks.

## 🛠️ How to Run This Project Locally
1. Clone or download this repository to your local drive.
2. Open the project root folder using **Visual Studio 2022 / 2026**.
3. Ensure the dependencies in the `/bin` directory are loaded properly.
4. Set your startup webpage template and press **Start Debugging (F5)** to launch the live web dashboard in your browser.
